# Agentic workflow demo

This package demonstrates a controlled Ask → Plan → Agent workflow in GitHub
Copilot using a Java runtime exception that is not covered by the starter tests.

## Run the prepared failure

From the repository root:

```powershell
.\demo\agentic-workflow\run-runtime-demo.ps1
```

## Materials

- `ask-plan-agent-java-runtime-demo.pptx` — presentation deck with speaker notes
- `presenter-transcript.md` — 30-minute talk track
- `PRESENTER-GUIDE.md` — rehearsal, expected failure and repair guidance
- `PROMPTS.md` — exact Ask, Plan and Agent prompts
- `run-runtime-demo.ps1` and `run-runtime-demo.cmd` — demo launchers
